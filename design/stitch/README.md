# Sunshine Dental — Stitch Redesign ("The Breathable Interface")

Full UI redesign of the Sunshine Dental web app, generated with **Google Stitch** from
[`DESIGN.md`](./DESIGN.md) (the "Digital Sanctuary" design system).

- **Stitch project:** `Sunshine Dental — Breathable Interface` (id `13701592793135615927`)
- **Design system asset:** `9c085a7a0bac4120a777a6b96d964f15`
- **Palette:** sage `#55624d` primary · blush `#755754` secondary · organic off-whites
- **Type:** Manrope (display/headlines) + Plus Jakarta Sans (titles/body)
- **Principles applied:** no 1px borders (tonal layering), xl rounded cards, ambient
  primary-tinted shadows, glassmorphism nav/sheets, signature 135° sage gradient CTAs.
